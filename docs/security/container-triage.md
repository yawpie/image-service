Pembaruan base/perl menutup CVE-2026-13221 yang memiliki fix, tetapi tidak seluruh CVE Perl. Pada dua runner Debian, probe `perl -MArchive::Tar` gagal memuat modul, paket/binary minizip dan systemd-homed tidak ditemukan; `infocmp`, `mount`, `nsenter`, serta `gzip` tetap ada. Effective capabilities bernilai nol. Keberadaan CLI dan library tetap dicatat; hasil probe tidak menjadi klaim seluruh library aman.

Build stages tetap memakai npm global untuk instalasi. Snapshot base sebelumnya menandai empat high, tujuh medium dan satu low di tool npm tersebut; versi npm build tetap 11.19.1. Tool ini dihapus dari runner yang tidak memerlukannya, sementara Prisma backend memakai CLI lokal yang telah diuji. Risiko build tetap perlu triase/pembaruan terjadwal: workflow tanpa secret pada PR, izin repository baca saja, input sintetis dan timeout. Image builder diperiksa terhadap canary, bukan dipindai penuh sebagai runtime; jangan membaca hasil runner nol sebagai hasil seluruh tooling build.

Temuan medium/low/unknown dipertahankan lengkap dalam JSON dengan pemilik dan tanggal review yang sama. Lihat [bukti container dan CI](container-ci-remediation.md) serta [triase dependensi dan feed historis](dependency-triage.md) untuk batas pengujian dan rollout.
