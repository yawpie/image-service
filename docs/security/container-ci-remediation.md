## Gate CI

Workflow memakai Ubuntu 24.04, Node 24, `npm ci --no-audit --no-fund` dari lockfile committed, izin repository `contents: read`, checkout tanpa credential tersimpan, history yang diperlukan, dan timeout. Action resmi dipatok commit; checkout/setup-node serta ketiga action Docker aktif backend sudah diperiksa memakai Node 24. Download Gitleaks 8.30.1 memeriksa SHA256 resmi sebelum eksekusi. Source dipindai lokal dan tidak dikirim ke layanan scanner.

Gate secret memeriksa checkout akhir **dan** rentang commit PR/push. Base SHA berasal dari event, divalidasi sebagai 40 karakter hex dan commit nyata; manual/first push memindai history HEAD. Kontrol sintetis membuktikan baseline bersih lulus, token yang ditambah terdeteksi, dan token yang kemudian dihapus tetap terdeteksi di history. Self-test mensyaratkan hitungan `leaks found` positif dari scanner dan output tanpa token, sehingga kegagalan operasional tidak dianggap keberhasilan deteksi. Base tidak valid ditolak tanpa shell interpolation.

Gate aktif memindai lockfile dengan Trivy 0.76.0 yang dipatok digest. Unduhan DB publik tidak memasang source; tahap scan kemudian memakai input manifest/lock read-only, network none, telemetry nonaktif, dan config/ignore kosong. Scope penuh memakai --include-dev-deps; produksi memakai default tanpa dev. Hash lock canonical LF (CRLF Windows dinormalisasi), inventaris paket lengkap, advisory/versi/severity/fix, DB/report segar dan expiry policy diperiksa. Sembilan tes RED/GREEN dan CLI aktual pada Node 24.22.0 Linux tanpa jaringan lulus untuk ketiga repo; fixture scanner nyata membuktikan pemisahan dev. Error/JSON malformed/target kosong/graph atau advisory baru/DB kedaluwarsa/policy lewat 2 November 2026 menggagalkan gate. Lihat [triase dan batas feed](dependency-triage.md) serta [ringkasan scan](dependency-scan-verification-2026-10-20.json).

## Scan, disposisi dan batas rilis

Trivy 0.76.0 memakai database 19 Oktober 2026 07:19:54 UTC, archive image final, tanpa network/Docker socket, dan tanpa filter severity. Hitungan aktual `{"debian": {"CRITICAL": 1, "HIGH": 58, "LOW": 87, "MEDIUM": 95, "UNKNOWN": 1}, "node-pkg": {"MEDIUM": 1}}`. [Triase satu per advisory high/critical](container-triage.md) dan [seluruh temuan JSON](container-vulnerabilities-2026-10-20.json) mempertahankan hasil mentah beserta hash report asli. Exit 0 bukan arti aman; disposisi tertunda wajib ditinjau maintainer sebelum rilis.

Batas yang tetap terbuka: CI remote pada PR, domain/origin dan cookie lintas layanan sebenarnya, topologi proxy/rate-limit, HTTPS/HSTS di platform, batas body/timeout proxy, izin volume upload/cache pada host, inventaris berkas lama dan transformasi Images provider. Root Compose lama juga masih memakai arg produksi HTTP serta mount/perintah development; koordinator tidak mengubah root non-Git. Operator harus menyelaraskannya dengan URL HTTPS backend dan CMD migrasi yang benar sebelum memakai jalur itu. Tidak ada bypass guard HTTPS untuk menyesuaikan Compose lama.

Migrasi backend `admin.is_active` wajib diterapkan lebih dulu sebelum provisioning diaktifkan. Migrasi image-service tetap job terpisah dari runner, karena Prisma CLI adalah dev dependency yang dipangkas. Volume harus dapat ditulis UID1000; izin volume produksi belum diuji.
